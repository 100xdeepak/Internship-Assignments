# Week 1 Task API

This project implements a simple Express-based task API with CRUD endpoints and Swagger documentation.

## Run locally

```bash
npm install
node server.js
```

## API documentation

Open http://localhost:3000/docs to view the Swagger UI for the task API.

## Endpoints

- GET /tasks
- POST /tasks
- GET /tasks/:id
- PUT /tasks/:id
- DELETE /tasks/:id
- GET /health
